📋 1. Общие положения

Настоящая политика конфиденциальности описывает правила обработки данных в мобильном приложении CatID — классификатор пород кошек по фото.

Мы придаём огромное значение защите вашей конфиденциальности. Приложение CatID разработано так, чтобы работать **полностью автономно (офлайн)** и гарантировать полную сохранность ваших снимков.

📷 2. Обработка фотографий (Офлайн-режим)

Вся обработка и анализ изображений происходит **исключительно локально на вашем устройстве** с использованием нейросетевых моделей приложения.

🔒 Ваши фотографии НЕ отправляются в сеть, НЕ загружаются на сторонние серверы и НЕ передаются третьим лицам. Они никогда не покидают ваше устройство.

📊 3. Какие данные мы НЕ собираем

Приложение CatID не собирает и не хранит:

  • ❌ Персональные данные (имя, email, телефон)
  • ❌ Геолокационные данные
  • ❌ Ваши снимки или историю распознаваний на внешних серверах
  • ❌ Список контактов или файлы устройства

📱 4. Разрешения устройства

Для корректной работы приложению могут потребоваться следующие разрешения:

  • 📷 Камера — для съемки кошки прямо из приложения.
  • 🖼️ Галерея / Фотографии — для выбора готового снимка из памяти устройства.

Эти разрешения используются строго по прямому назначению в момент работы с приложением.

🔒 5. Безопасность

Поскольку приложение работаeт локально и не передаёт фото по сети, риск утечки ваших личных изображений с нашей стороны полностью исключён.

👶 6. Дети

Приложение CatID полностью безопасно для пользователей любого возраста, включая детей, так как не собирает личные данные.
